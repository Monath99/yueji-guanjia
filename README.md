# 月季管家

给 SillyTavern 用的收藏与截图工具箱。手机端优先。

## 安装

### 方式一：从 GitHub 装（推荐）

1. 打开酒馆，点输入框左边的**扩展程序**按钮。
2. 找到 **安装扩展 / Install Extension**，把本仓库地址粘进去：

   ```
   https://github.com/<你的用户名>/yueji-guanjia
   ```

3. 点安装，装完**刷新页面**。

### 方式二：手动放文件夹

把本仓库的文件全部下载下来，放进酒馆的 `data/<你的用户名>/extensions/yueji-guanjia/` 目录，然后刷新页面。

目录里必须是这三个文件直接在根目录，不能再套一层文件夹：

```
yueji-guanjia/
 manifest.json
 index.js
 style.css
```

## 更新

从 GitHub 装的，在扩展程序面板里点这个扩展的**更新**按钮，然后刷新页面。

手动装的，重新下载覆盖这三个文件即可。

## 现在有什么

- 页面角落常驻一条浮动工具条，可以拖到任意位置。轻点条身收起成花苞，把花苞拖到屏幕边缘会自动吸附并藏起一半。
- 面板里有角色卡列表，点进任意角色就是它自己的收藏库。
- 收藏库里能按关键词搜索、删除（有二次确认），点任意一条可以看全文，也能复制、改名、删除。
- 能把楼层的正文收藏成带标题的文本：收藏库里点加号，从最近楼层里挑一条。
- **标签处理分两级**。默认所有 `<标签>` 的外壳都不会出现在收藏里，但标签里面的字保留（例如 `<高亮>重点</高亮>` 会变成「重点」）。列进**清洗标签**的那些，则会连里面的内容一起抹掉（例如把「时间」写进去，`<时间>22:10</时间>` 整段消失）。支持中文标签名。
- 文本收藏既能**按段落**挑，也能**整层收藏**。整层收藏取的是楼层原始文本，所以清洗标签只有在这条路上才起作用。
- 替换名词（文本侧）：只看不改。查看收藏时按规则显示替换后的文字，存下来的仍是原文。
- 替换名词（截图侧）：出图前把正文里的词换成别的词，例如把真名换成代称。
- 出图底色：经典白底、黑底白字、纯色自定义（背景色 + 字体色）、或者自定义图片背景。图片背景只有两种铺法：**拉伸铺满** 和 **平铺重复**。图片可以直接填地址，也可以从本机选一张（会自动压到 1280 像素以内再保存）。
- 字体：截图和文本收藏可以各选一种字体。内置楷体、宋体、黑体，以及作者常用的「月月特供版」。也支持粘贴自己的字体定义（`@import` / `@font-face`）保存成命名条目反复使用。
- **字体只作用在本插件里**。注入时会只挑出 `@import` 与 `@font-face` 这两类「定义」，其他规则（例如 `body { font-family:  }`）一律丢掉。所以不管粘贴什么都改不到酒馆本身的字体。
- 批量清理：文本库可以一键清空；截图库可以只删未星标的，也可以整个清空。
- 角色可以置顶，也可以按住拖动调整顺序。
- 夜间模式：浅色、深色、跟随系统三选一。
- 导出备份：把全部角色的文本收藏、番外指令和设置导出成一个 JSON 文件。图片不进备份。
- 番外指令备忘录：全局收藏，只做一层文件夹。按标题和正文搜索，一键复制到剪贴板，随时改和删。删文件夹时里面的指令会回到「未分类」，不会连坐删掉。
- **截图和文本收藏现在是同一套逻辑**：都在聊天页面上直接点段落选中。工具栏的截图按钮出图，文本收藏按钮存文本；面板里的加号也走同一条路。
- 挑段落时可以跳着挑。同一楼里挑中的段落按原顺序接成一段文字，中间没挑的不会被带进来。
- 面板图库里的加号仍可按段落挑，但只列最近 10 层。
- 图库里点任意一张可以看大图，并就地保存到本地、加星标、删除。
- 截图里的正文自动排除状态栏这类结构，模糊名词会遮成方块。
- 界面样式与酒馆主题相互隔离，不会互相影响。

## 关于截图

图片是把正文重新排版后画出来的，不是聊天界面的像素级复制没有头像、气泡，也没有消息里嵌的图片。换来的是跨楼层真正无缝、体积小、手机上不容易崩。

图片有单边和总像素上限，内容太长时会自动降低清晰度，实在放不下就只截前面几层并在界面上说明。这是为了避免手机上拿到一张空白图。

## 你的数据放在哪

所有内容都存在你自己浏览器的本地存储里，不会上传到任何服务器，作者也看不到。

导出的备份文件也只包含文字内容，图片不会进备份。
